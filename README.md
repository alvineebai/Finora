# Cloud Arcade

## What is this project?
This is an arcade project meant to create a game where end users can interact in any part of the world. They will be able to create accounts, save scores, and compete on a leaderboard


## Why are we building it?
We're using a real application to understand how cloud engineering works in practice—not just learning isolated tools. We'll connect application development, networking, containers, infrastructure as code, automation, identity, and security.


## What technologies will it use?
Azure, Docker, GitHub, Kubernetes, Terraform

We'll also use supporting technologies where needed, such as a programming language, a database, automated tests, and monitoring tools.


## How will someone eventually run it?
A player: visits a web address in their browser and plays the game.

A developer: obtains the source code, configures the required services, and runs the application locally or deploys it to a cloud environment.
