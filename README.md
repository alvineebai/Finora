# Finora

## What is this project?
Finora is a mobile-first digital banking platform that simulates the experience of using a modern bank. Customers will be able to sign in, view account balances, transfer simulated money between accounts, and review their transaction history. Future features will include transaction monitoring and fraud detection.


## Why are we building it?
We are using Finora to learn how real-world applications are designed, developed, deployed, and secured. The project combines application development, cloud engineering, DevOps, and cloud security in one hands-on experience.

The goal is to understand how each component works, how the components communicate, and how to build a reliable, scalable, and secure cloud application using industry practices.

## What technologies will it use?
Azure, Docker, GitHub, Kubernetes, Terraform

Microsoft Azure — cloud infrastructure and hosting

Git and GitHub — version control and source code management

Jira — project planning and work tracking

Docker — application containerization

Kubernetes and Azure Kubernetes Service (AKS) — container orchestration

Terraform — infrastructure as code

CI/CD pipelines — automated building, testing, and deployment

Application development and database technologies — to be selected as the application is designed

Security and monitoring tools — to support identity and access management, vulnerability management, logging, threat detection, and incident investigation

## How will someone eventually run it?
A customer: Opens Finora in a web browser on a mobile device or computer, signs in to a simulated account, views balances, and performs supported banking operations using fictional money.

A developer: Clones the GitHub repository, installs the required development tools, configures the application, and runs it locally using the documented setup instructions.

A cloud engineer: Uses Terraform and CI/CD pipelines to provision infrastructure and deploy the application to Azure, with Docker and Kubernetes introduced as the platform evolves.
